# 바이오 카트 전면 개편 프롬프트 — 스프라이트 스태킹 탑다운

## 0. 목표
- 바이오 카트(`games/bio-kart.html`)의 3D 복셀(three.js) 화면을 **스프라이트 스태킹(Sprite Stacking) 탑다운** 화면으로 바꾼다.
- 레이스 규칙·물리·AI·아이템·온라인(방장 권한 P2P/서버)·저장 데이터는 그대로 둔다. 화면을 그리는 층만 바꿔서 기존 기능이 깨지지 않게 한다.
- 대기실을 "8칸 레이서 카드 + 트랙 카드 + 기능 버튼" 구성으로 새로 만든다(첨부한 레이싱 게임 대기실의 **배치만** 참고). 이름·캐릭터·그림은 모두 이 게임의 생명과학 오리지널을 쓴다.
- 학교 크롬북·휴대폰에서 60fps에 가깝게 돌아가야 한다. WebGL 없이 Canvas 2D만 쓴다.

## 1. 스프라이트 스태킹 엔진
1. **복셀 모델**
   - `VX(w,d,h)` 빌더에 `box`, `ell`(타원체), `cyl`(세로 원기둥), `cone`, `ring`, `px` 도형으로 칠한다.
   - 1복셀 = 월드 1단위. 카트 길이는 약 22단위다.
2. **층 자르기**
   - 높이 z마다 w×d 캔버스 한 장을 만든다.
   - 아래층일수록 살짝 어둡게(AO 느낌), 맨 윗면은 밝게 칠한다.
3. **회전 캐시**
   - 모델마다 48방향을 미리 그려 둔다. 층을 아래부터 회전해서 화면 위쪽으로 `LAYER` 픽셀씩 올리며 쌓는다.
   - 실행 중에는 각도에 맞는 그림 1장만 그린다.
   - 캐시는 처음 쓸 때 만든다(지연 생성).
4. **그리기 크기**: 미리 그린 배율(2px/복셀)을 화면 줌에 맞춰 늘린다. 픽셀이 또렷하게 보이도록 smoothing은 끈다.
5. **정렬**: 화면 y가 작은 것(위쪽)부터 그린다. 점프 중인 카트는 그림자만 땅에 두고, 몸체는 위로 띄운다.

## 2. 카메라 · 월드 그리기
- **카메라**: 카트가 늘 화면 위쪽을 향하도록 따라 도는 체이스 탑다운 카메라.
  - 카트는 화면 아래 68% 지점에 둔다.
  - 속도·부스터·익시드에 따라 줌아웃한다(1.45→1.05).
  - 드리프트 때는 살짝 늦게 따라 돌게 해서 미끄러지는 느낌을 준다.
- **월드→화면**: `θ = -π/2 - CAM.a`, `screen = center + Rθ·(world-cam)·Z`.
- **바닥 타일**
  - 256×256 월드 단위 타일(1px=1단위)을 필요할 때만 그리고, LRU로 최대 70장까지 보관한다.
  - 내용: 트랙 밖 지형 무늬, 갓길, 도로(블록 무늬), 연석, 중앙 점선, 출발 체크무늬, 부스터 발판 화살표, 감속 진흙, 빙판, 점프대, 언덕 높이 음영.
  - 교차(오버패스) 구간은 높은 쪽 도로를 나중에 그린다.
- **벽**: 트랙 가장자리(`hw+30`) 바깥에 색이 번갈아 나오는 방호벽을 6층으로 쌓아 그린다. 다른 도로와 겹치는 곳은 생략한다.
- **장식**: 맵 테마의 `deco` 4종을 벽 바깥에 흩어 둔다. 거리에 따라 보일 때만 그리고, 바람·박동 같은 흔들림을 준다.
- **장애물**(osc·flow 등)·아이템 박스·바닥 아이템(점액·응고)·투사체(바이러스·효소)도 모두 스택 모델로 그린다.

## 3. 카트 · 캐릭터 · 펫 모델
- **카트 15종**: 모양(`round/disk/tank/flag/bean/leaf/spark/helix/compact/stack/spike/y/pac/muscle/plate`)마다 차체 실루엣을 다르게 한다.
  - 공통 부품: 바퀴 4개, 시트, 부스터 노즐, 번호판.
  - 색: 카트 `c1/c2`, 또는 차고에서 고른 색(`kc`).
- **캐릭터 15종**: 운전석 위의 크게 귀여운 머리.
  - 액세서리(`disk/blob/axon/bean/leaf/pac/dots/helix/virus/Y/drop/band/star/bolt/rod`)를 머리 위에 달아서, 위에서 봐도 누군지 알 수 있게 한다.
- **펫 8종**: 카트 옆에서 둥실 떠서 따라다닌다.
- **상태 연출(2D 덧그림)**
  - 드리프트 스파크(노랑→파랑→분홍), 스키드마크, 부스터 불꽃, 익시드 분홍 오라
  - 보호막 버블, 기절 케이지, 감속 표시
  - 순위 배지, 닉네임표

## 4. HUD · 연출
- 기존 HUD(순위·랩·미니맵·속도계·게이지·아이템 슬롯)는 그대로 쓴다.
- 3D에만 있던 백미러는 숨긴다.
- **화면 효과**: 부스터 테두리 빛, 속도선, 익시드 틴트, 피격 붉은 번쩍임, 급커브 표지판, 순간 부스터 링, 폭발·물보라 원형 파동.

## 5. 대기실(싱글) — 레이아웃
- **위 바**: 모드 · 방 제목 · 상태 문구 · 나가기
- **가운데: 8칸 레이서 카드(2줄×4)**
  - 카드 = 슬롯 번호, 이름표, 정보 아이콘, 스택 모델(카트+캐릭터) 미리보기
  - 아래에 상태 띠: 내 칸은 "방장", AI는 "준비 완료"
- **아래 왼쪽**: 트랙 소개·생명과학 지식 안내 상자(채팅창 자리)
- **아래 가운데**: 큰 트랙 카드(트랙 미니맵 + 이름 + 월드 + 난이도 별). 누르면 트랙 선택으로 간다.
- **아래 오른쪽 버튼**: 모드 변경 · 난이도 · 내 카트(차고) · 트랙 · 큰 "게임 시작(F5)"
- 차고와 트랙 선택에서 "뒤로"를 누르면 대기실로 돌아온다. 온라인 대기실 슬롯도 같은 카드 디자인을 쓴다.

## 6. 품질 기준
- 콘솔 오류 0개
- 스피드전·아이템전, 20개 트랙 모두 끝까지 완주(AI 자동 주행 시험)
- 온라인 로비 화면이 열리고 기존 요소 id가 그대로여야 한다.
- 썸네일: 새 탑다운 화면 + 대기실 느낌의 고해상도 이미지로 교체한다.
