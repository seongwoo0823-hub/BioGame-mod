# BIO ARCADE 교실 서버

선생님 컴퓨터 한 대가 **게임 사이트와 온라인 게임 중계를 함께** 맡습니다.
학생들은 같은 와이파이에서 선생님 컴퓨터 주소로 접속하고, 온라인 게임의 모든 메시지는 이 컴퓨터를 거쳐 바로 전달돼요.
인터넷 밖의 서버를 거치지 않아 빠르고, 학교 와이파이가 기기끼리 직접 연결(P2P)을 막아도 문제없어요.

## 준비 (처음 한 번)
1. **Node.js 설치**: https://nodejs.org → LTS 버전 내려받아 설치 (설치 옵션은 기본값 그대로)
2. **게임 파일 받기**: GitHub 저장소 화면 → 초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기
   (git을 쓴다면 `git clone`으로 받아도 됨. 새 버전이 나오면 다시 받거나 `git pull`)

3. **바탕화면 아이콘 만들기 (윈도우, 추천)**: 폴더의 `바탕화면 아이콘 만들기.vbs` 더블클릭
   → 바탕화면에 **'BIO 교실 서버'** 아이콘이 생기고, 방화벽 허용도 함께 물어봐요(관리자 확인 창에서 `예`)

## 수업할 때
1. 서버 켜기 (둘 중 하나)
   - **아이콘 방식(추천)**: 바탕화면의 **'BIO 교실 서버'** 아이콘 더블클릭 → 학생 접속 주소가 창에 뜨고 사이트가 열림.
     **끌 때도 같은 아이콘**을 누르고 `예`. (검은 창 없이 뒤에서 돌아가요)
   - 검은 창 방식: `start-server-windows.bat` 더블클릭 (맥: `start-server-mac.command` 또는 `서버 켜기 끄기 (맥).command`)
2. 윈도우에서 **방화벽 허용** 창이 뜨면 `개인`과 `공용` 네트워크를 **모두** 체크하고 `허용`
3. 검은 창에 나오는 **학생 접속 주소**(예: `http://192.168.0.12:8080`)를 칠판에 적어 주기
   - 선생님 컴퓨터에서 `http://localhost:8080`을 열면 메인 화면 아래에 학생 접속 주소가 크게 보여요
4. 학생들은 같은 와이파이에서 그 주소로 접속 → 온라인 게임 로비의 **'서버에 열린 방'** 목록에서 눌러서 참가
5. 수업이 끝나면 검은 창을 닫으면 서버가 꺼져요

## 온라인 게임 7종: 서버가 방장인 방 (자동)
- 교실 서버 주소로 연 온라인 게임(바이오 카트·바이오 비트·혈관 협곡·셀 브롤·바이오 스트라이크·바이오 타워·코돈 글래스)에서
  **'방 만들기'**를 누르면, 이 컴퓨터가 방장 역할(판 계산·판정·시간·순위)을 직접 맡아요.
  학생 기기는 모두 참가자라서 방장 기기 성능이나 방장이 나가는 것에 판이 흔들리지 않아요.
- 방을 만든 학생이 **방 관리자**(맵·모드·곡 선택, 시작). 관리자가 나가면 다음 학생이 자동으로 이어받아요.
- 방은 모두 합쳐 최대 16개. 아무도 없는 방은 1분 뒤 저절로 닫혀요. 방 상태 보기: `/__room/list`
- 방 하나에 메모리 약 50MB (방 8개를 동시에 열었을 때 서버 전체 약 430MB)
- GitHub Pages 주소로 열거나 서버 방을 만들 수 없으면 예전처럼 학생 기기가 방장이 돼요.

## 잘 안 될 때
- **휴대폰에서 주소를 열면 빈 화면에서 멈춰요** (가장 흔함):
  1. 주소 뒤에 `/hello`를 붙여 열어 보세요 (예: `http://192.168.0.12:8080/hello`). ✅ 화면이 나오면 네트워크는 정상.
  2. 서버 창(또는 사이트의 학생 접속 주소 상자)에 `📱 새 기기 접속`이 안 나오면 **연결 자체가 막힌 것**:
     - 노트북이 **랜선**으로 연결되면 윈도우가 그 네트워크를 **'공용'**으로 잡는 경우가 많고, 방화벽이 '개인'만 허용돼 있으면 휴대폰 접속이 막혀요
       → 폴더의 **`방화벽 허용.vbs`** 실행 (관리자 확인 창에서 `예`). 서버가 이 상황을 찾으면 경고로 알려 줘요.
     - 학교는 **유선망과 와이파이망이 분리**되어 있을 때가 많아요(서로 접속 불가). 노트북도 휴대폰과 **같은 와이파이**에 연결해 보세요.
       (와이파이에 연결하면 서버 창에 `(와이파이)` 주소가 따로 나와요. 그 주소를 쓰세요)
     - 게스트 와이파이는 기기끼리 접속을 막아요 → 교사용 와이파이 또는 선생님 휴대폰 핫스팟에 모두 연결
- **학생 기기에서 주소가 안 열려요**: 선생님 컴퓨터와 학생 기기가 같은 와이파이인지 확인.
  학교 와이파이가 기기끼리의 접속을 막는 경우(게스트 와이파이 등)가 있어요 → 교사용 와이파이를 쓰거나,
  선생님 휴대폰 핫스팟에 선생님 컴퓨터와 학생 기기를 함께 연결하면 됩니다.
- **방화벽 창에서 허용을 안 눌렀어요**: 폴더의 `방화벽 허용.vbs` 실행 (또는 윈도우 설정 → Windows 보안 → 방화벽 → 앱 허용 → `Node.js` 개인·공용 모두 체크)
- **8080번 포트를 이미 쓴다고 나와요**: 서버 창이 이미 하나 열려 있는지 확인. 다른 포트로 켜려면
  명령 프롬프트에서 `set PORT=8081 && node server\server.js` (맥: `PORT=8081 node server/server.js`)
- 메인 화면 위쪽 표시: `교실 서버 · 접속 N명`(정상) / `교실 서버 꺼짐`(서버 창이 닫힘)

## 동작 방식
- `server.js` 하나로 끝 (Node.js 기본 기능만 씀, `npm install` 필요 없음)
  - 저장소 폴더의 파일(index.html, games/…)을 그대로 보내 줌 (`.git`, `tools` 등은 숨김)
  - 웹소켓 중계: 방장은 `접두어+방코드`(예: `biostrike-v1-AB12`) 아이디로 접속, 참가자는 그 아이디로 연결 요청,
    게임 데이터는 해석하지 않고 상대에게 바로 전달
  - `/__status` 서버 상태 · `/__rooms?p=접두어` 열린 방 목록 · `/__info` 학생 접속 주소·진단 · `/hello` 연결 확인
  - 서버 방장: `/__room/new?game=…`(방 만들기) · `/__room/list`(방 상태) · 방마다 일꾼 스레드가 게임 코드를 그대로 돌림
    (바이오 카트: `kart-room.js`, 나머지: `game-room.js` — 화면 없이 게임 html을 불러오는 공용 일꾼)
- `net.js`(게임 쪽): 교실 서버가 보낼 때 맨 앞에 `window.BIO_LOCAL_RELAY=1`을 붙여 주면, 페이지를 연 그 서버로 중계.
  GitHub Pages 주소로 열면 예전처럼 기기끼리 직접(P2P) 연결
- 와이파이가 잠깐 끊겼다 붙으면 같은 '열쇠'로 다시 접속해 방을 그대로 되찾음
- 랭킹(Firebase)·글꼴(Google Fonts)은 인터넷이 필요해요. 인터넷이 없으면 랭킹만 안 되고 게임은 그대로 돌아가요

## 바이오 카트 서버 계산 성능 측정 (시험용)
'서버가 직접 판을 계산하는 방식(서버 권위)'으로 바꾸기 전에, 이 컴퓨터가 바이오 카트 방을 몇 개까지 감당하는지 재는 도구예요.
- 윈도우: `measure-kart-server-windows.bat` 더블클릭 / 맥: `measure-kart-server-mac.command` 더블클릭
- 또는 `node server/bench-kart.js` (짧게: `--quick`)
- 게임 그래픽은 쓰지 않고 `games/bio-kart.html`의 계산 코드만 불러와, 방마다 카트 8대(모두 AI)를 1초에 60번 계산하고
  실제와 같은 형식의 상태 전송(초당 25번)·입력 받기(초당 30번)를 흉내 내요. 지금 쓰는 교실 서버 동작에는 영향이 없어요.
