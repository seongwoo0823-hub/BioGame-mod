# BIO ARCADE 교실 서버

선생님 컴퓨터 한 대가 **게임 사이트와 온라인 게임 중계를 함께** 맡습니다.
학생들은 같은 와이파이에서 선생님 컴퓨터 주소로 접속하고, 온라인 게임의 모든 메시지는 이 컴퓨터를 거쳐 바로 전달돼요.
인터넷 밖의 서버를 거치지 않아 빠르고, 학교 와이파이가 기기끼리 직접 연결(P2P)을 막아도 문제없어요.

## 준비 (처음 한 번)
1. **Node.js 설치**: https://nodejs.org → LTS 버전 내려받아 설치 (설치 옵션은 기본값 그대로)
2. **게임 파일 받기**: GitHub 저장소 화면 → 초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기
   (git을 쓴다면 `git clone`으로 받아도 됨. 새 버전이 나오면 다시 받거나 `git pull`)

## 수업할 때
1. 압축을 푼 폴더에서
   - 윈도우: `start-server-windows.bat` 더블클릭
   - 맥: `start-server-mac.command` 더블클릭 (처음엔 오른쪽 클릭 → 열기)
2. 윈도우에서 **방화벽 허용** 창이 뜨면 `개인 네트워크`에 체크하고 `허용`
3. 검은 창에 나오는 **학생 접속 주소**(예: `http://192.168.0.12:8080`)를 칠판에 적어 주기
   - 선생님 컴퓨터에서 `http://localhost:8080`을 열면 메인 화면 아래에 학생 접속 주소가 크게 보여요
4. 학생들은 같은 와이파이에서 그 주소로 접속 → 온라인 게임 로비의 **'서버에 열린 방'** 목록에서 눌러서 참가
5. 수업이 끝나면 검은 창을 닫으면 서버가 꺼져요

## 잘 안 될 때
- **학생 기기에서 주소가 안 열려요**: 선생님 컴퓨터와 학생 기기가 같은 와이파이인지 확인.
  학교 와이파이가 기기끼리의 접속을 막는 경우(게스트 와이파이 등)가 있어요 → 교사용 와이파이를 쓰거나,
  선생님 휴대폰 핫스팟에 선생님 컴퓨터와 학생 기기를 함께 연결하면 됩니다.
- **방화벽 창에서 허용을 안 눌렀어요**: 윈도우 설정 → Windows 보안 → 방화벽 → 앱 허용 → `Node.js` 개인 네트워크 체크
- **8080번 포트를 이미 쓴다고 나와요**: 서버 창이 이미 하나 열려 있는지 확인. 다른 포트로 켜려면
  명령 프롬프트에서 `set PORT=8081 && node server\server.js` (맥: `PORT=8081 node server/server.js`)
- 메인 화면 위쪽 표시: `교실 서버 · 접속 N명`(정상) / `교실 서버 꺼짐`(서버 창이 닫힘)

## 동작 방식
- `server.js` 하나로 끝 (Node.js 기본 기능만 씀, `npm install` 필요 없음)
  - 저장소 폴더의 파일(index.html, games/…)을 그대로 보내 줌 (`.git`, `tools` 등은 숨김)
  - 웹소켓 중계: 방장은 `접두어+방코드`(예: `biostrike-v1-AB12`) 아이디로 접속, 참가자는 그 아이디로 연결 요청,
    게임 데이터는 해석하지 않고 상대에게 바로 전달
  - `/__status` 서버 상태 · `/__rooms?p=접두어` 열린 방 목록 · `/__info` 학생 접속 주소
- `net.js`(게임 쪽): 교실 서버가 보낼 때 맨 앞에 `window.BIO_LOCAL_RELAY=1`을 붙여 주면, 페이지를 연 그 서버로 중계.
  GitHub Pages 주소로 열면 예전처럼 기기끼리 직접(P2P) 연결
- 와이파이가 잠깐 끊겼다 붙으면 같은 '열쇠'로 다시 접속해 방을 그대로 되찾음
- 랭킹(Firebase)·글꼴(Google Fonts)은 인터넷이 필요해요. 인터넷이 없으면 랭킹만 안 되고 게임은 그대로 돌아가요
